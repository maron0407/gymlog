# 筋トレ記録（PWA版）

スマホのホーム画面から起動できる、トレーニング記録アプリです。オフラインでも動きます。

## ファイル構成

```
index.html             アプリ本体
manifest.webmanifest   アプリ名・アイコンの設定
sw.js                  オフライン対応（Service Worker）
*.png                  アイコン画像（icon-192 / icon-512 / icon-maskable-512 / apple-touch-icon）
```

## 1. GitHub Pages で公開する（無料・約10分）

1. https://github.com でアカウントを作成（持っていればログイン）
2. 右上の「＋」→「New repository」
   - Repository name：`gymlog` など好きな名前
   - **Public** を選択 → 「Create repository」
3. 作成後の画面で「uploading an existing file」をクリック
4. zip を解凍したフォルダの**中身**（index.html、manifest.webmanifest、sw.js、アイコン画像4つ、README.md）をまとめてドラッグ＆ドロップ → 「Commit changes」
5. リポジトリの「Settings」→ 左メニュー「Pages」
   - Source：「Deploy from a branch」
   - Branch：`main` / `/(root)` → 「Save」
6. 1〜2分待つと、`https://＜ユーザー名＞.github.io/gymlog/` で開けるようになります

> Netlify を使う場合は https://app.netlify.com/drop にフォルダごとドラッグするだけでも公開できます。

## 2. スマホにインストールする

**iPhone**
1. **Safari** で公開したURLを開く
2. 下の共有ボタン（□に↑）→「ホーム画面に追加」→「追加」

**Android**
1. **Chrome** で公開したURLを開く
2. 「アプリをインストール」の表示をタップ（出ない場合はメニュー︙ →「ホーム画面に追加」/「アプリをインストール」）

以降はホーム画面のアイコンから全画面で起動できます。

## 3. データについて（大切）

- 記録は**そのスマホの中だけ**に保存されます（サーバーには送られません）
- 次の場合はデータが消えるので、「履歴」タブ下の **「書き出す」** で定期的にバックアップしてください
  - アプリ（ホーム画面のアイコン）を削除したとき
  - ブラウザのデータ（履歴・Webサイトデータ）を消去したとき
  - 機種変更したとき
- 新しいスマホでは、同じURLからインストールして **「読み込む」** でバックアップファイルを選べば復元できます
- iPhoneでは、長期間（数週間）アプリを開かないとSafariがデータを消す場合があります。ホーム画面に追加して使っていれば基本的に大丈夫ですが、バックアップはおすすめです

## 4. トレーニングアドバイス（グラフタブ）

- **自動アドバイス**（無料・通信なし）：選んだ種目の記録から「次回の目安」と進め方のヒントを表示します
- **AIに相談**（任意・有料）：Claude（Anthropic のAI）が記録をもとに今後の進め方を文章でアドバイスします
  1. https://console.anthropic.com でアカウントを作り、クレジットを入れて API キーを作成
  2. アプリの「グラフ」タブ →「AIの設定（APIキー）」にキーを貼り付けて「保存」
  3. 種目を選んで「この種目についてAIに相談」
- キーはそのスマホの中だけに保存されます（GitHub やバックアップファイルには入りません）
- 相談するときは、その種目の記録・体重・身長・相談内容が Anthropic に送られます。費用は1回10円前後です

### AIトレーニング評価（記録タブの一番下）

- 記録タブで選んでいる日付のトレーニングを、Claude が **S・A・B・C・D の5段階** で評価します（APIキーが必要・1回10円前後）
- 目的（**筋肉増強／筋力維持**）を選ぶと、その目的に合わせて評価とコーチングをします。選んだ目的は保存されます
- 表示される内容：総合評価、種目ごとの評価と「良い点」「改善点（ひとつ上の評価にするには）」、今後1〜2週間のコーチング、次回のメニュー案
- 体調や相談を書いておくと考慮します。痛みやけがをうかがわせる内容があると注意が表示されます
- 評価結果はそのスマホに保存され、あとで同じ日を開くと表示されます（評価後に記録を変えると「記録が変わっています」と表示）
- 送る内容：その日と前回まで（最大5回分）の記録・メモ・体重・身長・目的・相談内容

## 部位の自動分類（記録タブの種目選び）

- 種目名のことばから部位（胸・背中・脚・肩・腕・腹）を自動で判断します。例：「ベンチ」「フライ」「プレス」→胸、「ラット」「ロウ」「チンニング」→背中、「レッグ」「スクワット」「ヒップ」→脚、「ショルダー」「レイズ」「リアデルト」→肩、「カール」「トライセプス」「リスト」→腕、「クランチ」「レッグレイズ」→腹
- 判断できない種目（例：ケーブルマシン、スミスマシン）は「その他」に入ります
- 種目を選ぶと「この種目の部位」が出るので、違っていたらそこで変えられます（変えた内容はバックアップにも入ります）

## 5. 休憩タイマー（記録タブ）

- 各セットの「✓（完了）」を押すと、セット間の休憩タイマーが自動でスタートします。「休憩スタート」ボタンで手動でも始められます
- 休憩時間は 30秒／1分／1分30秒／2分／3分 から選べます（選んだ時間は次回も使われます）
- タイマー中は画面下に残り時間が出ます。「−15秒」「＋15秒」で調整、✕で停止
- 0になると音とバイブ（対応端末のみ）で知らせます。タイマー中は画面が消えにくくなります（対応端末のみ）
- iPhoneでは、画面を消したり他のアプリに切り替えたりしている間は音が鳴りません（アプリに戻ると終了が表示されます）

## 6. アプリを修正・更新したとき

1. 変更したファイルを GitHub に再アップロード
2. `sw.js` の `const VERSION = "v1";` を `"v2"` のように上げてアップロード
3. スマホでアプリを一度閉じて開き直すと新しい版になります（ネットにつながっている時）

記録データは更新しても消えません。
